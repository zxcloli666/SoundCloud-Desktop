# Свой CSS

[English version](CUSTOM_CSS.md)

Настройки > Оформление > Свой CSS позволяют перекрасить приложение своим CSS. Изменения видны сразу, в главном окне и в мини-плеере из трея. Переключатель в заголовке карточки выключает стили, не удаляя их.

## Если стиль сломал интерфейс

- Нажмите **Ctrl+Alt+Shift+C** (**Cmd+Option+Shift+C** на macOS). Свой CSS выключится, повторное нажатие включит его обратно.
- Или запустите приложение с флагом `--no-custom-css`. Он выключает свой CSS до загрузки интерфейса:
  - Windows: допишите ` --no-custom-css` в конец поля «Объект» у ярлыка или запустите `soundcloud-desktop.exe --no-custom-css`.
  - macOS: `open -a soundcloud-desktop --args --no-custom-css`
  - Linux: `soundcloud-desktop --no-custom-css`

Сначала закройте запущенное приложение, иначе флаг попадёт в уже открытую копию и не сработает.

## Стабильные хуки

Классы Tailwind меняются от версии к версии. Эти атрибуты останутся:

| Селектор | Элемент |
|---|---|
| `[data-ui="app"]` | Вся рамка окна |
| `[data-ui="titlebar"]` | Заголовок с поиском и кнопками окна |
| `[data-ui="sidebar"]` | Левое меню |
| `[data-ui="main"]` | Прокручиваемая область страниц |
| `[data-ui="player"]` | Плавающая панель плеера |
| `[data-ui="queue"]` | Панель очереди |
| `[data-ui="lyrics"]` | Полноэкранный текст песни |
| `[data-ui="card"]` | Карточки настроек |
| `[data-ui="tray"]` | Мини-плеер в трее |
| `html[data-perf="light"]`, `"medium"` | Режим производительности (без атрибута — «Красота») |

## Переменные

| Переменная | Значение |
|---|---|
| `--color-accent` | Акцентный цвет |
| `--color-accent-hover` | Акцент при наведении |
| `--color-accent-glow` | Мягкое свечение акцента |
| `--color-accent-contrast` | Текст поверх акцента |
| `--bg-primary` | Фон окна |
| `--font-sans` | Шрифт интерфейса |
| `--glass-blur`, `--glass-blur-strong`, `--glass-blur-soft` | Размытие стеклянных панелей |

Акцент, фон и шрифт приложение берёт из настроек темы, поэтому при переопределении добавляйте `!important`:

```css
:root {
  --color-accent: #8b5cf6 !important;
  --bg-primary: #0b0614 !important;
}

[data-ui="sidebar"] {
  background: linear-gradient(180deg, rgba(139, 92, 246, 0.08), transparent);
}

[data-ui="card"] {
  border-radius: 18px;
}
```

Элементам, которые оформлены встроенными стилями, тоже нужен `!important`.

## Что блокируется

Правила `@import` и ссылки `url()` на интернет вырезаются перед применением, чтобы чужая тема не могла грузить файлы с других сайтов и подсматривать то, что вы вводите. `data:` и локальные файлы `asset:` работают. Для фоновой картинки используйте Настройки > Оформление > Фоновое изображение.
