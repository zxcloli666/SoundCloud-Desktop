# Темы

[English version](README.md)

Каталог тем для SoundCloud Desktop. Тема ставится в один клик: **Настройки -> Оформление -> Темы**.

## Добавить тему

1. Сделайте форк и ветку `theme/<id>`.
2. Создайте папку `themes/<id>/`:

   ```
   themes/<id>/
     theme.json      описание
     theme.css       стили
     preview.webp    скриншот
     assets/         картинки и шрифты, если нужны
   ```

3. Проверьте тему (Node 22.6 или новее, ставить ничего не нужно):

   ```
   node --experimental-strip-types themes/tools/check.mjs <id>
   ```

4. Откройте PR в `main`. Меняйте только свою папку.

После мержа тема появится в каталоге в течение часа. Установленные копии обновятся в течение нескольких часов.

## theme.json

```json
{
  "$schema": "../theme.schema.json",
  "id": "midnight",
  "name": "Midnight",
  "description": { "ru": "Глубокий синий и мягкое стекло", "en": "Deep blue with soft glass" },
  "version": "1.0.0",
  "author": { "name": "Your Name", "github": "your-login" },
  "license": "MIT",
  "accent": "#7aa2ff",
  "background": "#070a12",
  "font": "onest"
}
```

| Поле | Что писать |
|---|---|
| `id` | 3-32 символа: `a-z`, `0-9`, `-`. Совпадает с именем папки |
| `name` | До 32 символов |
| `description` | `ru`, `en`, `tr`, `ko`, хотя бы один язык, до 140 символов |
| `version` | `1.0.0`. Поднимайте при каждом изменении файлов |
| `author` | `name` до 40 символов, `github` - ваш логин |
| `license` | `MIT`, `Apache-2.0`, `CC0-1.0`, `CC-BY-4.0` или `CC-BY-SA-4.0` |
| `accent`, `background` | Необязательно. Цвет `#rrggbb` маленькими буквами |
| `scheme` | Необязательно. `dark` (по умолчанию) или `white`. Белой теме нужен `"minApp": "8.7.0"` |
| `font` | Необязательно. `inter`, `manrope`, `onest`, `golos`, `montserrat`, `rubik`, `nunito`, `raleway`, `comfortaa` или `system` |
| `minApp` | Только если теме нужно то, чего нет в старых версиях приложения |

Других полей быть не должно.

## theme.css

- Селекторы и переменные: [docs/CUSTOM_CSS.ru.md](../docs/CUSTOM_CSS.ru.md). Цепляйтесь за `[data-ui="..."]`, классы Tailwind меняются от версии к версии.
- Картинки и шрифты берите только из своей папки: `url("assets/bg.webp")`. Ещё можно `url(#id)` и `data:` с картинкой или woff2.
- Нельзя: ссылки на сайты, `@import`, `image()`, `src()`, `element()`, `paint()`, `var()` внутри `image-set()`, `behavior`, `-webkit-app-region`.
- @-правила: `@media`, `@supports`, `@keyframes`, `@font-face`, `@layer`, `@container`, `@property`, `@scope`, `@starting-style`.
- Режим "Лайт" (`html[data-perf="light"]`): уберите анимации и тяжелый blur.
- Схему, цвета, фон и шрифт приложение ставит само из `scheme`, `accent`, `background` и `font`. Чтобы перебить их в CSS, нужен `!important`.
- В белой теме задавайте цвета через переменные схемы (`--ink`, `--paper`, `--surface`, `--shade`), см. [Белая и тёмная](../docs/CUSTOM_CSS.ru.md#белая-и-тёмная).
- До 256 КБ.

Длинный текст в `content:` и `<text>` в SVG смотрим на ревью.

## Картинки и шрифты

- `assets/` без подпапок: до 24 файлов, каждый до 1 МБ, все вместе до 3 МБ.
- Картинка до 4096 px по каждой стороне, в `data:` тоже.
- Имя файла: `a-z`, `0-9`, `-`, `_`. Расширения: `webp`, `png`, `jpg`, `jpeg`, `avif`, `gif`, `svg`, `woff2`.
- Каждый файл должен использоваться в `theme.css`.
- SVG: без скриптов, ссылок наружу, `&...;` и обратного слеша, только пространства имен svg и xlink.

## Превью

- `preview.webp` или `preview.png`, ширина 960-1600, соотношение около 16:10, до 256 КБ. Лучше 1280x800.
- Нет скриншота? Все равно откройте PR. Проверка Themes снимет превью сама: скачайте `theme-previews` на странице запуска, положите `<id>/preview.webp` в свою папку и запушьте.

## Как проверить в приложении

1. **Настройки -> Оформление -> Свой CSS**: вставьте `theme.css`.
2. Картинки из `assets/` добавьте в **Свои картинки** под теми же именами. Шрифты (woff2) туда не добавить, их проверяйте по превью из CI.
3. Схему, цвет акцента, фон и шрифт выставьте руками в **Оформлении**.

Если интерфейс сломался: **Ctrl+Alt+Shift+C** (**Cmd+Option+Shift+C** на macOS).

## Обновить или удалить

- Обновить: поменяйте файлы и поднимите `version`. Без новой версии CI не пропустит.
- Удалить: PR, который удаляет папку.
